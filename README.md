# Sudip Sharma's personal website

A simple white GitHub Pages site with a blog. GitHub Pages builds the Markdown pages and posts automatically with Jekyll; no local software is required.

## Write a blog post on GitHub

1. Open this repository and click **Add file → Create new file**.
2. Name the file `_posts/2026-10-01-my-first-post.md`, replacing the date and title. The date must use `YYYY-MM-DD`; avoid a future date unless you want the post published later.
3. Paste this template and replace the text:

   ```markdown
   ---
   layout: post
   title: "My first post"
   date: 2026-10-01
   description: "A short summary for the blog list."
   ---

   Write your post here.

   ## A heading

   More text here.
   ```

4. Click **Commit changes**. GitHub Pages will publish the post and add it to the Blog page. The example in `_drafts/example-post.md` is a template and will not appear publicly.

To change a page, open its `.md` file, click the pencil icon, edit, and commit. To update the CV, upload a replacement PDF named `CV_Sharma_Sudip.pdf`.

Repository: `ssharma2712/ssharma2712.github.io`. In **Settings → Pages**, use **Deploy from a branch**, `master`, `/ (root)`.
